# Examples

The real runs behind the work, saved as they were sent to the Workflow tool. Read them for how specific a brief gets: who it's for, what was rejected, true details of the place, the anti-AI rules, the print limits, the process.

| run | result | what to learn from it |
|---|---|---|
| [crowd-line-ink.workflow.js](crowd-line-ink.workflow.js) | [images/crowd-line-ink.png](images/crowd-line-ink.png) | a named illustration reference; "build a small library of drawing primitives first" so the crowd is many people, not clones; heroes large, crowd thinning back. One artist, 3+ rounds. |
| [printmaker-map.workflow.js](printmaker-map.workflow.js) | [images/printmaker-map.png](images/printmaker-map.png), [images/printmaker-map-on-black.png](images/printmaker-map-on-black.png) | real geometry (OpenStreetMap) drawn by hand, not plotted; one expressive gesture (the sound rings); thinning toward a ragged edge. One artist, 3+ rounds. |
| [night-street.workflow.js](night-street.workflow.js) | (in progress) | the full loop: artist → critic → artist → critic → artist, 15+ rounds in total; the audience written into the brief after the owner rejected ideas for the wrong audience; style left to the artist ("this is not a map"). |

Those older runs predate the toolkit and the 1 mm rule: their minimum feature was 6 px, and the map uses fine stipple, which is too fine for DTG. Use OUTPUTS.md, not their numbers.
